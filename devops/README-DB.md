# SlivKino: база данных и админ-панель

## Как запускать

Для разработки используйте из корня проекта:

```bash
docker compose -f devops/compose.dev.yaml up --build
```

Откройте `http://localhost:3000/admin.html`. Админ-панель не следует запускать двойным щелчком по HTML: для чтения и сохранения SQLite нужен сервер.

## Что сохраняется

SQLite-файл `slivkino.sqlite` создаётся автоматически при первом запуске. В нём хранится состояние приложения: фильмы, кинотеатры, залы и бронирования. Админ-панель получает состояние с сервера и отправляет изменения в базу данных. Исходные JS-данные используются для первичного заполнения базы.

## Важно

Текущая версия не имеет полноценной аутентификации администратора. Не публикуйте сервер в интернете без авторизации, проверки прав и резервного копирования. Бронирования, создаваемые клиентскими страницами, не становятся автоматически серверными заказами, если логика бронирования не переведена на API.
