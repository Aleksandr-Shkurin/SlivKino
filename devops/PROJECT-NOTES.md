ИСПРАВЛЕНИЕ ФУНКЦИЙ «СЛИВКИНО» ДЛЯ LARAVEL

Что исправлено:
1. Поиск на главной странице по русскому и английскому названию фильма.
2. Фильтр фильмов по жанру через таблицу movie_genre; фильтр работает вместе с поиском.
3. Карточки кинотеатров открывают отдельную страницу с описанием и контактами.
4. На странице кинотеатра отображаются его залы и опубликованные сеансы.
5. Из карточки фильма и страницы кинотеатра можно перейти к выбору мест конкретного сеанса.
6. Схема мест строится по rows_count и seats_per_row из таблицы halls.
7. Занятые места считываются из таблицы bookings, новое бронирование записывается в MySQL на 15 минут.
8. Добавлена проверка повторного бронирования одного места в рамках транзакции.
9. Места из disabled_seats отображаются как места для маломобильных посетителей и остаются доступными для выбора — так же, как в исходном JavaScript проекта.

КАК УСТАНОВИТЬ
1. Сделайте резервную копию папки проекта или файлов, которые будут заменены.
2. Распакуйте содержимое архива непосредственно в корень проекта:
   C:\xampp\htdocs\slivkino_laravel
   Подтвердите замену файлов.
3. НЕ удаляйте и НЕ заменяйте .env, папку vendor и базу данных.
4. Откройте CMD в папке проекта и выполните:
   php artisan optimize:clear
   php artisan route:list
5. Запустите сайт:
   php artisan serve
   Откройте http://127.0.0.1:8000

ВАЖНО
- Таблица киносеансов называется movie_sessions.
- Промежуточная таблица жанров называется movie_genre.
- В модели Session задана таблица movie_sessions; в Movie и Genre явно задана movie_genre.
- Миграции менять и повторно выполнять не требуется, если таблицы уже созданы.
- Данные не удаляются. НЕ запускайте migrate:fresh.
- Если база пустая, запустите php artisan db:seed один раз. Если данные уже есть, повторный запуск текущего DatabaseSeeder может добавить дубликаты кинотеатров и фильмов.
- Бронирование демонстрационное: статус reserved на 15 минут. Реальная онлайн-оплата не подключена.

ПРОВЕРКА
- Главная: введите название фильма, выберите жанр и нажмите «Найти».
- Кинотеатры: откройте раздел «Кинотеатры», затем нажмите карточку кинотеатра.
- Сеансы: на странице кинотеатра или фильма нажмите «Выбрать места» у сеанса.
