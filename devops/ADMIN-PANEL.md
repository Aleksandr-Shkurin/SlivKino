# Административная панель «Сливкино»

## Возможности

- Фильмы: создание, изменение, удаление, постер, актёры, описания, статус проката и привязка жанров.
- Жанры: добавление, переименование и удаление.
- Кинотеатры: название, адрес, контакты, часы работы, описание и особенности.
- Залы: привязка к кинотеатру, количество рядов и мест, список VIP-мест и мест для маломобильных посетителей.
- Сеансы: фильм, зал, дата и время начала, цена билета.
- Бронирования: просмотр, фильтр по статусу, изменение статуса и удаление бронирования с освобождением мест.

## Установка в существующий проект

1. Сделайте резервную копию папки и базы `slivkino_db`.
2. Распакуйте файлы из этого архива с сохранением структуры поверх текущего Laravel-проекта `slivkino_laravel`.
3. Не заменяйте и не удаляйте `.env`, `vendor`, `public/images` и существующие пользовательские данные.
4. В терминале из корня проекта выполните:

   ```bat
   php artisan migrate
   ```

   Миграция добавляет пользователям поле `is_admin` со значением `false` по умолчанию. Существующие пользователи не получают права администратора автоматически.

5. Создайте администратора командой (адрес можно заменить на свой):

   ```bat
   php artisan app:create-admin admin@slivkino.local
   ```

   Команда интерактивно запросит имя и пароль. Пароль должен содержать не менее 10 символов. Он сохраняется в хешированном виде. Не используйте демонстрационный или легко угадываемый пароль.

6. Запустите сайт:

   ```bat
   php artisan serve
   ```

7. Откройте страницу входа:

   `http://127.0.0.1:8000/admin/login`

## Защита данных

- Все страницы изменения данных закрыты middleware `admin` и доступны только пользователям с `is_admin = 1`.
- Форма входа ограничена шестью попытками в минуту.
- Удаление фильма запрещено, пока у него есть сеансы; удаление зала — пока у него есть сеансы; удаление кинотеатра — пока у него есть залы; удаление сеанса — пока у него есть бронирования. Это защищает связанные записи от случайного каскадного удаления.
- Изменение фильма, зала или времени сеанса заблокировано, если у сеанса уже есть бронирования; цену изменить можно.
- Удаление бронирования освобождает выбранные места.
- Перед административной работой делайте резервную копию базы.

## Примечания

- Постер можно оставить по существующему относительному пути (например, `images/posters/film.jpg`) или загрузить изображение до 5 МБ. Загруженный файл помещается в `public/images/posters`.
- VIP-места и места для маломобильных посетителей вводятся через запятую в формате `ряд-место`, например `7-4, 7-5, 8-4`.
- Для выбора нескольких жанров в форме фильма удерживайте `Ctrl`.
- Для запуска панели не требуется `migrate:fresh` и не нужно повторно выполнять `db:seed`.
